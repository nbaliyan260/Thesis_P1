# RECUT changelog

This changelog separates experiment chronology from subsequent repository publication. Public-facing phase labels organize the project; they do not rename or pool its frozen internal studies.

## Phase 2 — Validated prototype publication — 16 September 2026

Release/tag: [`phase-2-validated-prototype`](https://github.com/nbaliyan260/Thesis_P1/releases/tag/phase-2-validated-prototype).

- Added internal Stage 2: detector-routed guarded multi-window transactions, private output, permanent full replay after token-history divergence, journal fallback and checkpoint refusal. Its main evidence contains 192 sessions, 512 commits and 32 specified refusals; it remains separate from later counts.
- Added internal Stage 3: pinned three-model study through Qwen2.5-7B, broader K/V and layer strata, native/bare clean cost references, full/sparse/all-cuts comparisons, batched-seal ablation, memory/availability accounting and independently reloadable state archives.
- Added the fourth report, *RECUT: Complete Prototype and Validation*, source/configuration freezes, raw JSON/JSONL evidence, independent audits, reporting tests and raw-result recomputation.
- Main Stage 3 evidence: 2,358 measured sessions; 6,966 exact-checked commits; 54 specified refusals; 21 archived states with 2,338 checked tensor pairs. Warmups, profiles, debug runs and the selected post-hoc fallback validation are kept separate.
- Published complete Stage 3 tensor evidence in `RECUT_Stage3_Validated_Artifact.zip`; new Stage 3 snapshot directories are excluded from Git. See the [Phase 2 guide](docs/phases/phase-2-transactional-validation.md) for its exact size, hash, download and full-audit instructions.
- Added two-phase navigation and combined historical/current evidence verification. Stage 2 and Stage 3 retain their original paths because dependencies and frozen records refer to them.
- Preserved the original Stage 3 analyzer and summaries. Reporting-only corrected summaries disclose refused-window seal-counter display corrections without changing measured times, outcomes or performance claims.
- Updated shared PDF rendering support and the research landing documentation. These are later changes, not byte-identical Phase 1 artifacts; original versions remain available at the immutable Phase 1 commit. Historical evidence manifests are not regenerated to hide those differences.

The Stage 2/3 experiment reports and frozen documentation contain statements such as “no GitHub update” or “no automatic GitHub push.” Those describe the experiment stages when recorded. This separately requested publication occurred afterward; historical files were not rewritten to alter their chronology.

The engineering milestone is complete within its declared scope. This release does not claim a completed thesis, production deployment, novel general recovery principle or A/A* readiness. The latest report prominently records clean protection costs and output-delay limitations.
